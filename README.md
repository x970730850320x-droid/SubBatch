# SubBatch — 字幕完整性修正版

本 fork 基于 [itchaox/SubBatch](https://github.com/itchaox/SubBatch) 的 `40880bbf`，保留原作者署名与 MIT 许可证。当前修正版为 **2.0.1-fork.1**；它与原作者 Chrome／Edge 商店安装包分别维护。

## 修正版的变化

- 按字幕段落解析时间轴，保留纯数字正文、多行正文、繁体中文与真实重复句。
- TXT／MD／复制保留原文；DOCX 使用真正的 OOXML 文档结构。旧 `doc` 格式设置自动迁移为 `docx`。
- 新用户的文字导出默认附标题、链接、作者和发布日期；既有明确设置（包括不附信息）保持不变。
- 转写区分完整、部分完成、失败。部分结果在界面、文件名与文字正文保留警示；SRT 另附转写报告，记录失败区块和缺失时间范围。
- 如果某个转写区块有文字却没有有效时间戳，整份结果保留为无时间轴文字，并记录对应区块；可导出 TXT／MD／DOCX，SRT 导出会明确提示缺少时间轴，不编造时间戳或丢弃文字。
- 本地模型预检与初始化放在音频下载前；缺模型时给出明确错误，不自动连接模型托管服务。
- 转义标题、作者和错误状态的 HTML，收紧未使用的代理/CDN 权限；Cookie 日志继续脱敏。
- 增加真实源码函数回归、完整侧栏模拟交互测试和 GitHub Actions 验证。

### 安装与验证

本项目无生产构建步骤。下载修补分支的源码或通过 CI 下载 `SubBatch-extension` artifact，解压至包含 `manifest.json` 的目录，在桌面 Chrome／Edge 扩展管理页选择“加载已解压的扩展”。这是独立安装的 fork，不会替换原作者商店版本。

开发验证需要 Node.js 22 或更新版本；浏览器使用扩展不需要安装 Node.js。

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run package
```

安装包输出在 `dist/`，只包含运行资源、模型目录、使用说明与许可证。CI 上传的是相同打包流程的产物。仓库与 CI 默认**不包含 ONNX 模型权重**，既有字幕提取不依赖这些模型；本地语音转写请先阅读 [模型配置](MODEL_SETUP.md)。

### 当前验证边界

测试使用模拟 B 站响应和测试用 Cookie，不读取真实账户，也不替代实时 B 站接口、浏览器 GPU、音频下载与 Whisper 推理的端到端验证。音频转写保留 60 分钟上限；批次清单仍属于当前侧栏会话，尚无跨重启任务恢复、CLI／MCP 或 NotebookLM 自动同步。原始技术笔记 `test.md`、`REAEME-AI.md` 记录了历史实现，当前行为以代码、本说明和测试为准。

## 🌟 插件介绍

SubBatch 是一个浏览器扩展插件，专为批量获取和导出 B 站视频字幕而设计。它可以获取单个或批量视频的字幕数据，并支持导出为 SRT、TXT、MD 或 DOCX 文件，适合用于 AI 知识库建设（如 NotebookLM）、学习笔记整理或视频内容分析。

> **非官方声明**：SubBatch 是独立开发的第三方工具，与哔哩哔哩（Bilibili）无关，也不代表哔哩哔哩官方立场或获得其官方授权。

> 💡 特别适合将 B 站优质内容转化为个人 AI 知识库的素材，一键批量导出纯文本格式，无需手动复制粘贴！

## ✨ 主要功能

- **🎬 批量获取字幕**：同时处理多个 B 站视频的字幕数据
- **📥 多种导入方式**：支持单个视频 URL、当前页面地址、整个收藏夹导入
- **📤 灵活导出格式**：
  - **SRT 格式**：包含时间轴的标准字幕格式，适合播放器使用
  - **TXT / MD 格式**：保留原文的文本内容，可供知识库或笔记使用
  - **DOCX 格式**：可供 Word 或兼容软件打开的 OOXML 文档
- **📊 视频列表管理**：表格化展示所有导入的视频，清晰直观
- **🔄 批量处理**：一键操作，节省时间
- **🔒 隐私保护**：本地处理数据，不上传到第三方服务器！

## 📋 使用指南

### 🚀 快速开始

1. 安装扩展后，点击浏览器工具栏中的 SubBatch 图标
2. 在弹出的侧边栏中使用以下任一方法添加视频：
   - 输入 B 站视频 URL 并点击"添加到表格"
   - 在 B 站视频页面点击"获取视频地址"按钮
   - 在 B 站收藏夹页面点击"获取收藏夹"按钮

## 🔍 详细使用流程

### 1️⃣ 获取视频字幕

1. 通过以上提到的任一方式将视频添加到表格
2. 点击"获取字幕"按钮开始批量获取字幕
3. 进度条会显示当前处理进度
4. 获取完成后，表格中的字幕状态会更新为"已获取"或错误信息

### 2️⃣ 导出字幕文件

1. 确保至少有一个视频的字幕状态为"已获取"
2. 在设置中选择导出模式和导出文件格式，默认是 ZIP 压缩 + TXT
3. 点击"导出字幕"按钮：
   - **SRT 格式**：包含时间轴和序号的标准字幕格式，适合导入播放器
   - **TXT / MD 格式**：保留字幕正文，分别导出为 `.txt`、`.md` 文件
   - **DOCX 格式**：将字幕正文写入真正的 `.docx` 文档
4. 选择 `ZIP 压缩` 会下载一个 ZIP 压缩包；选择 `单个文件` 会一次性创建多个字幕文件下载任务

### 3️⃣ 使用收藏夹批量导入

1. 打开 B 站收藏夹页面
2. 点击"获取收藏夹地址"按钮或手动复制 URL 到收藏夹地址输入框
3. 点击"获取收藏夹视频"按钮
4. 收藏夹中的所有视频将被添加到表格中

## 💡 使用技巧

- **选择合适的格式**：
  - 用于视频剪辑或研究时间轴 → 选择 SRT 格式
  - 用于 AI 知识库或文本分析 → 选择 TXT、MD 或 DOCX 格式
- **选择导出模式**：想一次下载一个压缩包 → 选择 ZIP 压缩；想直接得到一组字幕文件 → 选择单个文件
- **浏览器下载确认**：如果 Chrome 开启了“下载前询问每个文件的保存位置”，单个文件模式仍会按文件弹出保存确认，需要在浏览器下载设置中关闭该选项
- **批量处理**：先将所有需要的视频添加到表格，然后一次性获取字幕，提高效率
- **字幕筛选**：如果某些视频获取失败，可先清除，再重试单个视频
- **Cookie 设置**：对于部分需要登录才能观看的视频，需设置 Cookie 才能获取字幕

## 🛠️ 常见问题

- **字幕获取失败**：检查视频是否有字幕，或尝试设置 Cookie
- **收藏夹导入失败**：确认收藏夹 URL 格式正确，可能需要设置 Cookie
- **下载的 ZIP 文件打不开**：ZIP 压缩模式下请使用最新版解压软件，或检查是否下载完整

## 📊 AI 知识库应用场景

SubBatch 特别适合用于构建个人知识库，尤其是与 NotebookLM 等 AI 工具配合使用：

1. 使用 SubBatch 批量导出感兴趣 B 站视频的字幕为 TXT、MD 或 DOCX 格式
2. 将纯文本字幕文件导入 NotebookLM 或其他 AI 笔记工具
3. 利用 AI 对内容进行总结、提取要点或生成学习笔记
4. 建立个人专题知识库，随时通过 AI 助手检索和学习
